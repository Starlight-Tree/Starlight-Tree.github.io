I build web apps with FastAPI, Next.js and Postgres: screens, API, database and tests, with design decisions kept in written records (ADRs).

Projects

All three are demos set in a fictional world (the planet Zahard). No real shops, people or documents are used.

ShopOrder

FastAPI · Next.js · TypeScript · Postgres · Docker Compose

An ordering app for a fictional café chain: store pickup and delivery on screen, a prep board and stock for staff, and sales, time-of-day and customer analytics for managers. Stock is an append-only ledger, so the same item is never sold twice. Chat ordering exists as a backend only so far.

DocuNavi

FastAPI · LangGraph · Gemini · pgvector · Next.js

A RAG chatbot that answers from PDF documents and shows its sources. The sample documents are fictional.

JobNavi

FastAPI · Next.js · Postgres

A job board for botanical gardens on a fictional planet: search and detail pages for job postings.
